### T01 · 同义改写 · 上个月的不合格率最高的三家厂商是谁？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：口径错
- 说明：行数相同但取值不同 ｜ 实测 (东莞精诚五金制品有限公司, 8.30) ≠ 基准 (东莞市佳合线材有限公司, 2.00) ｜ 实测 (宁波恒力精密铸造有限公司, 4.44) ≠ 基准 (东莞精诚五金制品有限公司, 7.66)
- 归一后意图：`{"指标": "来料不良率", "维度": ["供应商"], "排序": {"按": "度量", "方向": "降序"}, "限制": 3, "时间": "上月", "过滤": [{"字段": "检验判定", "运算符": "精确", "值": "不合格"}]}`
- 实测 SQL：

```sql
SELECT s.供应商名称 AS 供应商, ROUND(SUM(i.不良数量) * 100.0 / NULLIF(SUM(i.抽检数量), 0), 2) AS 不良率
FROM 到料检验 i
JOIN 供应商 s ON s.供应商编码 = i.供应商编码
WHERE i.检验判定 = '不合格'
  AND i.到料日期 >= '2026-08-01' AND i.到料日期 < '2026-09-01'
GROUP BY s.供应商名称
ORDER BY 不良率 DESC
LIMIT 3
```

### T15 · 口语 · 库存不够的料都是谁供的？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「供应商名称」（实测列：物料编码、物料名称、物料类别、库存合计、安全库存、水位百分比）
- 归一后意图：`{"指标": "库存安全水位", "维度": ["物料"], "过滤": [{"字段": "物料编码", "运算符": "精确", "值": "料"}], "聚合后过滤": true}`
- 实测 SQL：

```sql
SELECT m.物料编码 AS 物料编码, m.物料名称 AS 物料名称, m.物料类别 AS 物料类别, ROUND(SUM(k.库存数量), 0) AS 库存合计, m.安全库存 AS 安全库存, ROUND(SUM(k.库存数量) * 100.0 / m.安全库存, 1) AS 水位百分比
FROM 库存 k
JOIN 物料 m ON m.物料编码 = k.物料编码
WHERE k.物料编码 = '料'
GROUP BY m.物料编码, m.物料名称, m.物料类别, m.安全库存
HAVING SUM(k.库存数量) < m.安全库存
ORDER BY 水位百分比 ASC
```

### T16 · 口语 · 买得最多的那家还供什么料？

- 判据：处置（结果集比对）
- 实测类型：SQL ｜ 分类：该澄清却硬答
- 说明：给出了可执行 SQL —— 硬答：WITH 最高 AS (   SELECT 供应商编码 FROM 到料检验    GROUP BY 供应商编码   ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DE
- 实测 SQL：

```sql
WITH 最高 AS (
  SELECT 供应商编码 FROM 到料检验 
  GROUP BY 供应商编码
  ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DESC LIMIT 1
)
SELECT DISTINCT m.物料编码, m.物料名称, m.物料类别
FROM 最高 h
JOIN 采购订单 p ON p.供应商编码 = h.供应商编码
JOIN 物料 m ON m.物料编码 = p.物料编码
ORDER BY m.物料编码
```
