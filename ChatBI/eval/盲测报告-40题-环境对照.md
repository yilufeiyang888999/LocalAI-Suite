### T01 · 同义改写 · 上个月的不合格率最高的三家厂商是谁？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「供应商」（实测列：物料编码、物料名称、供应商名称、不良率）
- 归一后意图：`{"场景": "C11_主要供应商不良率超标", "参数": {"阈值": 5, "时间": "上月"}}`
- 实测 SQL：

```sql
WITH 主供 AS (
  SELECT 物料编码, 供应商编码,
         ROW_NUMBER() OVER (PARTITION BY 物料编码 ORDER BY SUM(订单金额) DESC) AS 名次
  FROM 采购订单 GROUP BY 物料编码, 供应商编码
),
不良 AS (
  SELECT 供应商编码, SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) AS 不良率
  FROM 到料检验 WHERE 到料日期 >= '2026-08-01' AND 到料日期 < '2026-09-01' GROUP BY 供应商编码
)
SELECT m.物料编码, m.物料名称, s.供应商名称, ROUND(b.不良率, 2) AS 不良率
FROM 主供 z
JOIN 物料 m ON m.物料编码 = z.物料编码
JOIN 供应商 s ON s.供应商编码 = z.供应商编码
JOIN 不良 b ON b.供应商编码 = z.供应商编码
WHERE z.名次 = 1 AND b.不良率 > 5
ORDER BY m.物料编码
```
- 系统说明：⚠️ 问题里提到了「检验判定=不合格、检验判定=合格」，但这次查询**没有按它筛选** —— 这个结果把它的范围也一起算进去了。只想看它的话，请再问一次并点名。

### T02 · 同义改写 · 八月份 IQC 不良率最高的是哪家？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「供应商」（实测列：物料编码、物料名称、物料类别）
- 归一后意图：`{"场景": "C12_最高不良供应商所供物料", "参数": {"时间": "2026年8月"}}`
- 实测 SQL：

```sql
WITH 最高 AS (
  SELECT 供应商编码 FROM 到料检验 WHERE 到料日期 >= '2026-08-01' AND 到料日期 < '2026-09-01'
  GROUP BY 供应商编码
  ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DESC LIMIT 1
)
SELECT DISTINCT m.物料编码, m.物料名称, m.物料类别
FROM 最高 h
JOIN 采购订单 p ON p.供应商编码 = h.供应商编码
JOIN 物料 m ON m.物料编码 = p.物料编码
ORDER BY m.物料编码
```

