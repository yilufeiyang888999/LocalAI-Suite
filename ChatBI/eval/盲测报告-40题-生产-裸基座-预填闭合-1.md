### T09 · 同义改写 · 东莞精诚最近半年的不良率走向？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「月份」（实测列：供应商、不良率）
- 归一后意图：`{"指标": "来料不良率", "维度": ["供应商"], "过滤": [{"字段": "供应商名称", "运算符": "模糊", "值": "东莞精诚"}], "时间": "近6个月"}`
- 实测 SQL：

```sql
SELECT s.供应商名称 AS 供应商, ROUND(SUM(i.不良数量) * 100.0 / NULLIF(SUM(i.抽检数量), 0), 2) AS 不良率
FROM 到料检验 i
JOIN 供应商 s ON s.供应商编码 = i.供应商编码
WHERE s.供应商名称 LIKE '%东莞精诚%'
  AND i.到料日期 >= '2026-04-01' AND i.到料日期 < '2026-10-01'
GROUP BY s.供应商名称
ORDER BY 不良率 DESC
```

```sql
SELECT m.物料编码 AS 物料编码, m.物料名称 AS 物料名称, m.物料类别 AS 物料类别, ROUND(SUM(k.库存数量), 0) AS 库存合计, m.安全库存 AS 安全库存, ROUND(SUM(k.库存数量) * 100.0 / m.安全库存, 1) AS 水位百分比
FROM 库存 k
JOIN 物料 m ON m.物料编码 = k.物料编码
GROUP BY m.物料编码, m.物料名称, m.物料类别, m.安全库存
ORDER BY 水位百分比 ASC
```

### T24 · 错别字 · 上个月不良率最高的前五家供货商？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「供应商」（实测列：物料编码、物料名称、物料类别）
- 归一后意图：`{"指标": "来料不良率", "基础查询": "枚举", "目标": "供应商", "场景": "C12_最高不良供应商所供物料", "参数": {"时间": "上月"}}`
- 实测 SQL：

```sql
WITH 最高 AS (
  SELECT 供应商编码 FROM 到料检验 WHERE 到料日期 >= '2026-08-01' AND 到料日期 < '2026-09-01'
  GROUP BY 供应商编码
  ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DESC LIMIT 1
)
SELECT DISTINCT m.物料编码, m.物料名称, m.物料类别
FROM 最高 h
JOIN 采购订单 p ON p.供应商编码 = h.供应商编码
JOIN 物料 m ON m.物料编码 = p.物料编码
ORDER BY m.物料编码
```
