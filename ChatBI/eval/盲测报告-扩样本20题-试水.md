## 五、失败清单（这是要拿去改的输入）

### T41 · 同义改写 · 上个月抽检量最大的五家供应商是哪些？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「抽检合计」（实测列：供应商、不良率）
- 归一后意图：`{"指标": "来料不良率", "维度": ["供应商"], "排序": {"按": "度量", "方向": "降序"}, "限制": 5, "过滤": []}`
- 实测 SQL：

```sql
SELECT s.供应商名称 AS 供应商, ROUND(SUM(i.不良数量) * 100.0 / NULLIF(SUM(i.抽检数量), 0), 2) AS 不良率
FROM 到料检验 i
JOIN 供应商 s ON s.供应商编码 = i.供应商编码
GROUP BY s.供应商名称
ORDER BY 不良率 DESC
LIMIT 5
```

### T42 · 同义改写 · 苏州瑞恒最近半年交了多少批货？

- 判据：结果集（结果集比对）
- 实测类型：SQL ｜ 分类：缺列
- 说明：缺列「到料批次」（实测列：供应商、准时率）
- 归一后意图：`{"指标": "准时交付率", "维度": ["供应商"], "时间": "近6个月", "过滤": []}`
- 实测 SQL：

```sql
SELECT s.供应商名称 AS 供应商, ROUND(SUM(CASE WHEN i.到料日期 <= p.约定交期 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) AS 准时率
FROM 采购订单 p
JOIN 到料检验 i ON i.采购订单号 = p.采购订单号
JOIN 供应商 s ON s.供应商编码 = p.供应商编码
WHERE p.约定交期 >= '2026-04-01' AND p.约定交期 < '2026-10-01'
GROUP BY s.供应商名称
ORDER BY 准时率 ASC
```
