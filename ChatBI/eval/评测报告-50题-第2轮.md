### 失败题的实测 SQL

**A04** 库存低于安全库存的物料有哪些？

```sql
SELECT COUNT(*) AS 物料数
FROM 物料
```

**B06** 上月哪家供应商不良率最高？

```sql
WITH 最高 AS (
  SELECT 供应商编码 FROM 到料检验 WHERE 到料日期 >= '2026-08-01' AND 到料日期 < '2026-09-01'
  GROUP BY 供应商编码
  ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DESC LIMIT 1
)
SELECT DISTINCT m.物料编码, m.物料名称, m.物料类别
FROM 最高 h
JOIN 采购订单 p ON p.供应商编码 = h.供应商编码
JOIN 物料 m ON m.物料编码 = p.物料编码
ORDER BY m.物料编码
```

**B08** 2026 年 8 月不良率排名前 5 的供应商？

```sql
WITH 最高 AS (

  ORDER BY SUM(不良数量) * 100.0 / NULLIF(SUM(抽检数量), 0) DESC LIMIT 1
```

**B09** 宁波恒力精密铸造的准时交付率是多少？

```sql
SELECT ROUND(SUM(CASE WHEN i.到料日期 <= p.约定交期 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) AS 准时率
FROM 采购订单 p
JOIN 到料检验 i ON i.采购订单号 = p.采购订单号
ORDER BY 准时率 ASC
```

**B26** 2026 年 8 月宁波恒力的不良率是多少？

**C39** 生产工单达成率最低的物料类别是哪个？

```sql
SELECT m.物料类别 AS 物料类别, ROUND(SUM(w.完工数量) * 100.0 / NULLIF(SUM(w.计划数量), 0), 1) AS 达成率
FROM 生产工单 w
JOIN 物料 m ON m.物料编码 = w.物料编码
GROUP BY m.物料类别
ORDER BY 达成率 DESC
LIMIT 1
```

## 六、判据与边界（诚实标注）

1. **列超集容忍**：实测列是基准列的超集即算对（投影到基准列比对）。列名与语义层渲染一致 —— 列名是定义里的稳定契约。
2. **拒答率与误拒率分开**：混在一起会把两种相反的错抵销掉。
3. **分母固定**：不可执行题不从分母剔除。
4. **单指标覆盖缺口**：本集只覆盖语义层已定义的 5 指标 + 基础查询 + 3 场景。以下类型**本次测不到**，不是通过：① 聚合后过滤只对库存水位开放（「不良率超过 X% 的供应商」这类问法**渲染不出来**，属能力缺口）；② 双指标同表对比（不良率与采购金额并列）不支持；③ 跨表任意关联（模型不能自选 JOIN）。
5. **每档 10~15 题，分辨力约 ±7~10 pp**（1 题 ≈ 6.7~10 pp）；单看一两题的差异不构成结论。
