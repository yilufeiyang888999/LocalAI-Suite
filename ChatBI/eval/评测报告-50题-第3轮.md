### 失败题的实测 SQL

**A03** 2026 年 8 月总共抽检了多少件？

```sql
SELECT ROUND(SUM(i.抽检数量), 0) AS 抽检数量合计
FROM 到料检验 i
```

**A04** 库存低于安全库存的物料有哪些？

```sql
SELECT COUNT(*) AS 物料数
FROM 物料
```

**C14** 各物料类别的不良率对比？

```sql
SELECT i.主要不良原因 AS 主要不良原因, COUNT(*) AS 条数
FROM 到料检验 i
GROUP BY i.主要不良原因
ORDER BY 条数 DESC
```

**B33** 各供应商类别的不良率对比？

```sql
SELECT i.主要不良原因 AS 主要不良原因, COUNT(*) AS 条数
FROM 到料检验 i
GROUP BY i.主要不良原因
ORDER BY 条数 DESC
```

**B34** 2026 年 8 月各供应商的不良率分别是多少？

```sql
SELECT i.主要不良原因 AS 主要不良原因, COUNT(*) AS 条数
FROM 到料检验 i
WHERE i.到料日期 >= '2026-08-01' AND i.到料日期 < '2026-09-01'
GROUP BY i.主要不良原因
ORDER BY 条数 DESC
```

## 六、判据与边界（诚实标注）

1. **列超集容忍**：实测列是基准列的超集即算对（投影到基准列比对）。列名与语义层渲染一致 —— 列名是定义里的稳定契约。
2. **拒答率与误拒率分开**：混在一起会把两种相反的错抵销掉。
3. **分母固定**：不可执行题不从分母剔除。
4. **单指标覆盖缺口**：本集只覆盖语义层已定义的 5 指标 + 基础查询 + 3 场景。以下类型**本次测不到**，不是通过：① 聚合后过滤只对库存水位开放（「不良率超过 X% 的供应商」这类问法**渲染不出来**，属能力缺口）；② 双指标同表对比（不良率与采购金额并列）不支持；③ 跨表任意关联（模型不能自选 JOIN）。
5. **每档 10~15 题，分辨力约 ±7~10 pp**（1 题 ≈ 6.7~10 pp）；单看一两题的差异不构成结论。
