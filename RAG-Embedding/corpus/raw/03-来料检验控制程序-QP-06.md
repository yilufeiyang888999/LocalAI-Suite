## 1. 目的

规定外购原材料、外协加工件到厂后的检验流程、抽样方法、判定规则与不合格处置，确保不合格物料不流入生产环节。

## 2. 适用范围

2.1 适用于本公司所有**外购物料**的到货检验（Incoming Quality Control，以下简称 IQC）。

2.2 适用于外协表面处理件回厂后的复检。

2.3 **不适用**于自制件的过程检验与成品检验（分别见 QW-QC-01、QW-QC-02）。

## 3. 职责

| 部门 | 职责 |
|---|---|
| **采购部** | 下达采购订单；推动供应商按期交货；协调不合格品的退换与索赔 |
| **仓储部** | 到料签收、卸货、暂存「待检区」，并在到料当日通知品质部报检 |
| **品质部（IQC）** | 执行检验、判定、出具报告、维护检验记录；跟踪不合格品处置 |
| **工艺部** | 判定标准的技术解释；参与重大不合格的技术评审 |
| **生产部** | 对判定结论有异议时提出复检申请 |

> **待检区隔离原则**：未完成检验的物料**一律不得进入生产现场**，须存放在仓储部指定的「待检区」（原料仓东侧，黄色地坪标识）。擅自挪用按 **QP-08** 第 7.2 条处理。

## 4. 工作程序

### 4.1 报检

4.1.1 物料到厂后，仓储部当日完成签收并在系统中登记，同时以《到料报检单》通知品质部 IQC。

4.1.2 报检时须提供：采购订单号、物料编码、到料数量、送货单、供应商随批检验报告（如有）。

4.1.3 **同一采购订单分多次到料的，每次到料分别报检、分别出具检验单。**

### 4.2 抽样方案

4.2.1 本公司按 GB/T 2828.1《计数抽样检验程序》的框架，结合历史质量水平，**采用简化固定比例抽样**（经主要客户书面认可），具体如下：

| 到货批量 N（件） | 抽检数量 | 说明 |
|---|---|---|
| N < 375 | **30 件**（下限） | 小批量统一按下限抽检 |
| 375 ≤ N < 1000 | **N × 8%**，取整 | |
| N ≥ 1000 | **80 件**（上限） | 大批量不再增加抽检量 |

**计算公式**：`抽检数 = min(80, max(30, 到货数量 × 8%))`

> **为什么设下限 30**：早期版本曾将下限设为 10 件。在小批量场景下，若实际不良率约 2%，10 件样本抽到 0 件不良的概率很高，导致**月度不良率被系统性低估**。自 C 版起下限改为 30 件，历史数据已按新规则追溯重算。

4.2.2 抽样应**随机抽取**，覆盖不同包装箱、不同托盘位置。只从最上层取样、或只抽同一箱的，检验结果视为无效。

4.2.3 以下情形**加严检验**：抽检数在上表基础上**加倍**，且判定阈值由 3% 收紧至 **1.5%**：

- 供应商为新准入（首批 3 批）；
- 供应商评级为 **C 级**或处于**观察期**；
- 上一批被判不合格；
- 品质部认为有必要时。

4.2.4 以下情形可**放宽检验**（抽检数取上表的一半，但不低于 15 件）：连续 20 批合格且供应商评级为 **A 级**。放宽检验由品质部书面批准后执行。

### 4.3 检验项目与方法

| 检验项目 | 方法 / 依据 | 适用物料 |
|---|---|---|
| 外观 | 目视，D65 光源，距离 300 mm | 全部 |
| 尺寸 | 通用量具（卡尺 / 千分尺 / 塞规） | 按图样 |
| 材质 | 材质证明书核对 + 必要时光谱分析 | 全部（核对） |
| 表面处理 | 见 4.4 | 有表面处理要求的件 |
| 功能/性能 | 按物料技术协议 | 电子元件、密封件等 |
| 包装与标识 | 目视，核对标识与送货单一致性 | 全部 |

### 4.4 表面处理件的专项检验

对有镀层要求的物料（含 A10001 不锈钢法兰盘、A10013 平垫圈、A10025 传动轴等），除外观与尺寸外，**须核对供应商随批检验报告**中的以下项：

| 项目 | 我方验收标准 | 依据 |
|---|---|---|
| 镀层厚度 | 装饰性 5 ~ 8 μm；功能性 8 ~ 12 μm | GB/T 9799 |
| 附着力（划格法） | **≤ 1 级**（0 级最优） | **GB/T 9286** |
| 附着力（热震） | 200 °C × 30 min 后水淬，不起泡不脱落 | GB/T 5270 |
| 中性盐雾 | ≥ 48 h 无白锈；功能性件 ≥ 72 h 无红锈 | GB/T 10125 |
| 外观 | 无起泡、麻点、露底、烧焦 | —— |

**验收标准的统一性**：上述标准对**自制件与外购件统一适用**，与 **QW-DD-03** 第 6.2 节一致。区别只在于：自制件由我方工艺实现，外购件由供应商自行选择实现方式。

IQC 常规检验以**外观与尺寸**为主；镀层厚度、附着力、盐雾**以供应商随批报告为凭**，我方**每月至少一次**抽取留样自行复测。

### 4.5 判定规则

4.5.1 **批次不良率** = 抽检不良数 ÷ 抽检数量。

4.5.2 判定结论**仅两种**，记录于检验单「检验判定」栏：

| 判定 | 条件 |
|---|---|
| **合格** | 批次不良率 **≤ 3%** |
| **不合格** | 批次不良率 **> 3%** |

> **注意**：本公司**不设「让步接收」这一独立判定值**。需要让步接收的批次，其判定栏仍记为「**不合格**」，另在《不合格品评审记录》（QR-QC-08-02）中记录让步结论与批准人。**查询历史数据时须注意这一点** —— 只看「检验判定」栏会漏掉实际已让步放行的批次。

4.5.3 加严检验批次的合格阈值见 4.2.3。

### 4.6 不合格品处置

4.6.1 判定不合格的批次，IQC 立即在物料外包装加贴**红色「不合格」标签**，并通知仓储部转入不合格品区（原料仓西侧，红色地坪）。

4.6.2 处置路径按 **QP-08《不合格品控制程序》** 执行，常见四种：

| 处置方式 | 说明 | 批准人 |
|---|---|---|
| 退货 | 整批退回供应商 | 品质部部长 |
| 让步接收 | 不影响装配与功能时，经技术评审后降级使用 | **技术副总** |
| 挑选使用 | 由供应商派人或我方代为全检，费用由供应商承担 | 品质部部长 |
| 报废 | 无使用价值 | 总经理 |

4.6.3 **不合格批的触发动作**：同一供应商**连续 2 批**或**近 3 个月内累计 3 批**判不合格的，品质部须：

1. 发出《纠正措施要求书》（SCAR），要求供应商 **7 个工作日内**提交 8D 报告；
2. 该供应商评级**下调一级**（A→B→C）；
3. 纳入加严检验（见 4.2.3）。

4.6.4 供应商评级与准入状态的变更按 **QP-07《供应商管理程序》** 执行。

### 4.7 检验记录

4.7.1 检验完成后，IQC 当日将结果录入系统，生成**检验单号**：

```
IQC + 到料日（yyMMdd）+ 4 位流水号
例：IQC2608150001
```

4.7.2 检验单字段如下（**系统内字段名与本节一致**，便于查询）：

| 字段 | 说明 |
|---|---|
| 检验单号 | 见 4.7.1 编码规则 |
| 采购订单号 | 关联 `采购订单` 表 |
| 物料编码 | 关联 `物料` 表 |
| 供应商编码 | 关联 `供应商` 表 |
| 到料日期 | 实际到料日（**注意：采购订单表中无「实际到料日期」字段，须由本表反推**） |
| 抽检数量 | 按 4.2.1 计算 |
| 不良数量 | 抽检中判定为不合格的件数 |
| 主要不良原因 | **单值**，取本批占比最高的原因（原因清单见附录 A） |
| 检验判定 | **合格** / **不合格** |

4.7.3 纸质记录保存 **3 年**，电子记录长期保存。

## 7. 附录 A · 主要不良原因清单

IQC 记录「主要不良原因」时**须从下表中选择，不得自行造词**（保证数据可统计）：

| 分类 | 原因 |
|---|---|
| **尺寸与形位类** | 尺寸偏差、形位公差超差、螺纹不良 |
| **外观类** | 表面毛刺、外观划痕 |
| **材料类** | 材质硬度不符 |
| **表面处理类** | 表面镀层厚度不达标、镀层附着力不足、镀层起泡 |

> **统计口径提示**：表面处理类三项（镀层厚度不达标 / 附着力不足 / 起泡）**同源**，通常同时出现。当某供应商某月「表面处理类」占比显著上升时，应优先排查其**表面处理工艺是否发生变更**，而非按偶发质量问题处理。
