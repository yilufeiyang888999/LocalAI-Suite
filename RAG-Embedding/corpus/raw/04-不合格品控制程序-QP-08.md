## 1. 目的

规定本公司**不合格品**（含外购、外协、自制、成品）的标识、隔离、评审、处置及纠正措施要求，防止不合格品被误用、误流或非预期交付。

## 2. 适用范围

2.1 适用于本公司**所有来源**的不合格品：

| 来源 | 发现环节 | 主要责任部门 |
|---|---|---|
| 外购件 | 到货检验（IQC） | 品质部 |
| 外协加工件 | 回厂复检 | 品质部 |
| 自制件 | 过程检验 | 生产部 / 品质部 |
| 在制品 | 转序检验 | 生产部 |
| 成品 | 出厂检验 | 品质部 |
| 客户退回 | 客户投诉处理 | 品质部 / 销售部 |

2.2 **不适用**于到货检验的抽样与判定规则本身（见 **QP-06《来料检验控制程序》**）及供应商准入与评级（见 **QP-07《供应商管理程序》**）。

## 3. 职责

| 部门 / 岗位 | 职责 |
|---|---|
| **品质部** | 不合格品的判定、标识、记录；组织评审；监督处置执行；发出 SCAR |
| **工艺部** | 提供技术判定意见；参与让步接收的技术评审 |
| **生产部** | 执行返工 / 返修；配合原因分析（8D 中的 D4、D5） |
| **采购部** | 联系供应商退换货、索赔；跟踪供应商 8D 报告 |
| **仓储部** | 物理隔离不合格品；按处置结论执行出入库 |
| **总经理** | 批准报废；批准重大让步接收 |
| **技术副总** | 批准一般让步接收 |

## 4. 不合格品的标识与隔离

4.1 **发现即标识**。任何人发现不合格品，**立即停止该工序流转**并通知品质部，不得自行处理。

4.2 品质部判定后，在物料外包装加贴标签：

| 标签颜色 | 含义 |
|---|---|
| **红色** | 不合格（待处置） |
| **黄色** | 待检 / 待判定 |
| **绿色** | 合格（已放行） |

4.3 **隔离区域**：

| 区域 | 位置 | 存放内容 |
|---|---|---|
| 不合格品区 | 原料仓西侧（红色地坪） | 外购、外协不合格件 |
| 待检区 | 原料仓东侧（黄色地坪） | 未完成检验的到货物料 |
| 返工区 | 装配车间北侧 | 待返工件 |

4.4 **隔离原则**：不合格品在处置结论作出前**不得离开隔离区域**，不得与合格品混放，不得被生产领用。

> **待检区同样适用**：未完成检验的到货物料一律不得进入生产现场。擅自挪用待检区或不合格品区物料的，按**第 7.2 条**处理。

## 5. 不合格品的评审与处置

### 5.1 评审组织

5.1.1 不合格批次由品质部发起评审，评审形式分为：

| 情形 | 评审方式 | 参与人 |
|---|---|---|
| 常规不合格 | 品质部内部评审 | IQC 主管 + 品质部部长 |
| 涉及技术判断 | 技术评审 | 加工艺部 |
| 让步接收 | 技术评审 | 加技术副总（批准） |
| 重大 / 批量性 | 专题评审会 | 品质、工艺、生产、采购负责人 |

5.1.2 评审结论填于《不合格品评审记录》（**QR-QC-08-02**），评审记录须保存 **3 年**。

### 5.2 处置方式

本公司对不合格品**只允许以下四种处置方式**，不得采用其他方式（如擅自挑选后当合格品入库）：

| 处置方式 | 说明 | 批准权限 |
|---|---|---|
| **退货** | 整批退回供应商，本公司不承担后续 | 品质部部长 |
| **让步接收** | 经技术评审确认**不影响装配与功能**时，降级使用；须记录让步结论与批准人 | **技术副总** |
| **挑选使用** | 由供应商派人或我方代为全检，分出可用件；**全检费用由供应商承担** | 品质部部长 |
| **报废** | 无使用价值或返工不经济 | **总经理** |

> **与 IQC 判定栏的关系**：让步接收在系统中**不单独设判定值**。按 **QP-06 第 4.5.2 条**，此类批次的「检验判定」栏仍记为「**不合格**」，让步结论只体现于本程序的 QR-QC-08-02 记录。**这是有意设计** —— 避免统计口径出现第三种值导致月度不良率不可比。

### 5.3 表面处理类缺陷的特别规定

表面处理件（镀锌 / 镀镍 / 化学氧化等）的处置与一般机加工件不同，缺陷类型直接决定能否返工：

| 缺陷类型 | 是否可返工 | 处置方式 |
|---|---|---|
| **起泡**（含针尖状） | **不得返工** | **直接报废** |
| 局部未镀覆 / 露底 | 可返工（退镀后重镀） | 返工 |
| 钝化膜发花 | 可返工 | 返工 |
| 镀层厚度不达标 | 可返工（补镀） | 返工 |
| 附着力不足 | 视基体状态判定 | 返工或报废 |

> **起泡件为何不得返工**：起泡意味着基体与镀层之间已存在夹层或氢聚集。退镀需再次酸洗，氢脆风险叠加，且夹层无法彻底消除 —— 返工后的件在客户处失效的风险高于报废损失。故按本条规定**直接判报废**。
>
> 外购表面处理件判为起泡的，**一律退货**，不得由我方返工（我方不具备供应商的工艺条件，返工质量无保证）。

### 5.4 处置执行与验证

5.4.1 处置结论作出后 **1 个工作日内**，仓储部按结论执行出库（退货 / 报废）或转入返工区。

5.4.2 **返工件必须重新检验**，检验方法与新件一致，不得免检放行。

5.4.3 报废件由仓储部按《废弃物管理要求》处理，**不得流入废品回收渠道后被二次使用**。

## 6. 纠正与预防措施

### 6.1 触发条件

出现下列情形之一，品质部须向责任方发出《纠正措施要求书》（**SCAR**）：

| 情形 | 责任方 |
|---|---|
| 同一供应商**连续 2 批**判不合格 | 供应商 |
| 同一供应商**近 3 个月内累计 3 批**判不合格 | 供应商 |
| 同一缺陷在厂内**重复出现 3 次以上** | 内部责任部门 |
| 客户投诉 / 退货 | 视原因定 |
| 批量报废金额 ≥ 5 万元 | 视原因定 |

### 6.2 8D 报告要求

6.2.1 SCAR 发出后，供应商须在 **7 个工作日内**提交 **8D 报告**，内容至少包含：

| 步骤 | 内容 |
|---|---|
| D1 | 成立小组（含责任人与联系方式） |
| D2 | 问题描述（含批次号、数量、不良率） |
| D3 | 临时遏制措施（在途 / 库存品如何处理） |
| D4 | **根本原因分析** |
| D5 | 纠正措施 |
| D6 | 措施验证与效果确认 |
| D7 | **预防措施**（防止同类问题再次发生） |
| D8 | 小组总结与表彰 |

6.2.2 **8D 报告不接受「操作人员疏忽」作为唯一根本原因**。此类回复一律退回重做，要求追溯到**流程 / 参数 / 防错**层面。

6.2.3 逾期未提交 8D 的，采购部按 **QP-07** 的规定暂停该供应商的新订单下达。

### 6.3 措施有效性验证

6.3.1 纠正措施实施后，品质部须**连续跟踪 3 批**来料，确认不良率回到正常水平。

6.3.2 跟踪期内仍出现同类不合格的，**升级处理**：由技术副总牵头专题评审，必要时启动供应商降级或暂停。

### 7.2 违规处理

7.2.1 **擅自挪用**待检区或不合格品区物料的：

1. 首次：责任人书面检讨，扣发当月绩效 20%；
2. 再次：扣发当月绩效 50%，部门主管连带 20%；
3. 造成客户投诉或批量损失的，按公司《质量事故处理规定》处理。

7.2.2 **隐瞒不报**（发现不合格品未通知品质部而自行处理）的，从重处理。

7.2.3 **擅自放行**（未经评审将不合格品当合格品流转）的，无论是否造成后果，一律按重大违规处理。

## 附录 B · 常见缺陷与建议处置（供评审参考）

| 缺陷 | 常见来源 | 建议处置 |
|---|---|---|
| 尺寸偏差 / 形位公差超差 | 机加工、冲压 | 视超差量：可修则返工，不可修则报废或让步 |
| 表面毛刺、划痕 | 机加工、搬运 | 返工（去毛刺 / 抛光） |
| 材质硬度不符 | 热处理、材料替代 | **退货**（无法通过加工补救，且涉及材质合规） |
| 螺纹不良 | 攻丝、磕碰 | 返工（回攻）或报废 |
| 镀层起泡 | 表面处理 | **报废**（见 5.3） |
| 镀层附着力不足 | 表面处理 | 返工或报废，需工艺部判定 |
| 镀层厚度不达标 | 表面处理 | 返工（补镀） |
