## 1. 目的

规定本公司供应商的**开发、准入、绩效评价、分级管理与淘汰**规则，确保外购件质量稳定、交付及时，并与供应商建立可追溯的绩效记录。

## 2. 适用范围

2.1 适用于向本公司提供**生产用物料、外协加工服务**的全部供应商。

2.2 **不适用**于设备采购、办公用品、物流服务类供应商（另见 QP-04）。

## 3. 术语

| 术语 | 说明 |
|---|---|
| **准入状态** | 供应商与我方的合作关系状态，取值：**合格** / **观察期** / **暂停** / **淘汰** |
| **供应商评级** | 对合格供应商的**绩效等级**，取值：**A** / **B** / **C**，每季度评定一次 |
| **观察期** | 因质量或交付问题被限期整改的状态，**期限 6 个月** |
| **SCAR** | 纠正措施要求书，见 QP-08 |
| **首件** | 新供应商或变更后首批来料 |

> **⚠️ 常见混淆**：**准入状态**与**供应商评级**是两个独立字段，不可混为一谈。
> 举例：一家供应商可能**准入状态 = 合格**但**评级 = C**（绩效差但仍合格）；
> 也可能**准入状态 = 观察期**且**评级 = C**（问题严重到被限期整改）。
> 统计时按需选择正确字段，**用错字段会得出完全不同的名单**。

## 4. 职责

| 部门 | 职责 |
|---|---|
| **采购部** | 供应商开发、商务谈判、合同签订、订单下达；组织绩效评价 |
| **品质部** | 供应商质量绩效数据提供；参与现场审核；发起质量相关的降级 / 观察期建议 |
| **工艺部** | 技术能力评估；样品与首件的技术判定 |
| **财务部** | 供应商结算、价格绩效数据提供 |

## 5. 供应商开发与准入

### 5.1 准入流程

```
供应商申请 / 采购部推荐
        │
        ▼
① 资料评审 ────────────── 营业执照、资质证书、体系证书
        │                    （ISO 9001 为基本要求）
        ▼
② 样品验证 ────────────── 工艺部 + 品质部
        │
        ▼
③ 小批量试产 ──────────── 首批 3 批，加严检验（见 QP-06 §4.2.3）
        │
        ▼
④ 现场审核 ────────────── 关键物料供应商必做
        │                    （五金件、铸件、电子元件、密封件）
        ▼
⑤ 批准准入 ────────────── 准入状态置为「合格」，初始评级 **B**
```

### 5.2 各环节要求

| 环节 | 要求 | 责任人 | 时限 |
|---|---|---|---|
| 资料评审 | 证书在有效期内；经营范围覆盖所供物料 | 采购部 | 5 个工作日 |
| 样品验证 | 样品检验合格；必要时做小批试装 | 品质部 / 工艺部 | 10 个工作日 |
| 小批量试产 | **首批 3 批全部加严检验**，判定阈值 1.5% | 品质部 | —— |
| 现场审核 | 审核生产与检验能力、过程控制、追溯性 | 品质部 + 采购部 | 1 个工作日 |
| 批准 | 总经理批准（关键物料）或采购部部长批准 | —— | 3 个工作日 |

5.3 **新准入供应商的初始评级一律为 B**，连续 4 个季度绩效达标方可升为 A。

5.4 关键物料的**供应商数量不少于 2 家**（避免单一来源风险）。A10001、A10025 等表面处理件**至少备选 1 家**。

## 6. 供应商绩效评价

### 6.1 评价周期与维度

6.1.1 **每季度评价一次**，数据来源为本季度内全部到料批次的检验与交付记录。

6.1.2 评价采用四维度加权：

| 维度 | 权重 | 数据来源 | 计算口径 |
|---|---|---|---|
| **质量** | 40% | `到料检验` 表 | 季度不良率 |
| **交付** | 30% | 到料日期 vs 约定交期 | 季度准时交付率 |
| **价格** | 20% | `采购订单` 表 | 价格竞争力（同比 / 市场比价） |
| **服务** | 10% | 采购部评价 | 响应速度、配合度、8D 及时性 |

### 6.2 质量维度评分标准

| 季度不良率 | 得分 |
|---|---|
| ≤ 0.5% | 100 |
| 0.5% ~ 1.5% | 85 |
| 1.5% ~ 3.0% | 70 |
| 3.0% ~ 5.0% | 50 |
| > 5.0% | **0** |

### 6.3 交付维度评分标准

| 季度准时交付率 | 得分 |
|---|---|
| ≥ 95% | 100 |
| 90% ~ 95% | 85 |
| 80% ~ 90% | 70 |
| 70% ~ 80% | 50 |
| < 70% | **0** |

> **准时交付率的计算口径**：以**到料检验表**中的「到料日期」与**采购订单表**中的「约定交期」比对，**到料日期 ≤ 约定交期** 记为准时。分母为**本季度内实际到料的批次数**。
> **注意**：采购订单表中**没有「实际到料日期」字段**，实际到料日须由到料检验表反推（见 **QP-06 第 4.7.2 条**）。用订单表的「约定交期」直接统计会得到错误结果。
>
> **另注**：约定交期晚于统计截止日、尚未到料的订单**不计入分母**（否则会把「还没到」算成「不准时」）。

### 6.4 综合得分与评级对应

| 综合得分 | 评级 | 管理措施 |
|---|---|---|
| ≥ 85 | **A** | 可申请放宽检验（连续 20 批合格后，见 QP-06 §4.2.4）；优先分配新订单 |
| 70 ~ 85 | **B** | 常规管理 |
| < 70 | **C** | **加严检验**（QP-06 §4.2.3）；新订单份额下调 |

## 7. 分级管理与激励

### 7.1 待遇差异

| 项目 | A 级 | B 级 | C 级 |
|---|---|---|---|
| 检验强度 | 可放宽（50% 抽样） | 常规 | **加严（200% 抽样，阈值 1.5%）** |
| 付款条件 | 可申请月结 60 天 | 月结 30 天 | 货到付款或月结 15 天 |
| 新订单 | 优先 | 常规 | **受限**（须采购部部长批准） |
| 现场审核频次 | 每 2 年 | 每年 | **每半年** |

### 7.2 评级调整规则

7.2.1 **降级**触发条件（满足任一）：

| 条件 | 降级幅度 |
|---|---|
| 单季度综合得分 < 70 | 降一级 |
| 同一供应商连续 2 批判不合格 | **降一级**（且发 SCAR，见 QP-08 §6.1） |
| 近 3 个月内累计 3 批判不合格 | **降一级** |
| 8D 报告逾期未交或质量低劣（以「人员疏忽」为由反复退回） | 降一级 |
| 发生重大质量事故（致客户停线 / 退货） | **直接降为 C** |

7.2.2 **升级**触发条件（须同时满足）：

1. 连续 **2 个季度**综合得分 ≥ 85；
2. 期间**无**不合格批次（不良率 0）；
3. 准时交付率 ≥ 95%；
4. 无逾期未交的 8D。

7.2.3 评级调整**每季度统一发布一次**（见 7.4），降级条件成立后**在下一次评级发布时生效** —— 因此系统中查询到的评级，可能**滞后于**最近一个月的质量数据。这是有意设计：评级须经完整季度数据支撑，避免单月波动导致频繁升降。

> **实务提示**：当某供应商当月质量数据已明显恶化、但系统中评级尚未下调时，**不得以「评级仍是 B 级」为由维持常规检验强度**。此时应按 7.3.1 评估是否直接进入观察期，或临时按 C 级管理。
>
> **例外**：发生重大质量事故（致客户停线 / 退货）的，可由技术副总批准**即时降级**，不等季度发布。

### 7.3 观察期与淘汰

7.3.1 **进入观察期**的触发条件（满足任一）：

| 条件 | 说明 |
|---|---|
| 评级**连续 2 个季度为 C** | 限期整改 |
| 单季度不良率 > 5%（且供货物料为关键件） | 直接进入观察期 |
| 发生伪造检验报告、擅自变更工艺未通知等**诚信问题** | 直接进入观察期 |
| 重大质量事故 | 直接进入观察期 |

7.3.2 观察期**期限 6 个月**。期内措施：

- 全部批次**加严检验**（抽样加倍，阈值 1.5%）；
- **停止新订单下达**（执行中的订单继续）；
- 要求提交**整改计划**，每月报告进展；
- 每 2 个月由品质部现场复查一次。

7.3.3 观察期**期满评估**：

| 结果 | 处理 |
|---|---|
| 整改达标（连续 3 个月不良率 ≤ 1.5%，无不合格批） | 解除观察期，准入状态恢复「合格」，评级保留为 C |
| 整改不达标 | 转入「暂停」，停止全部合作，寻找替代供应商 |
| 诚信问题未澄清 | **直接淘汰** |

7.3.4 **淘汰**的供应商 **12 个月内不得重新申请准入**。

### 7.4 评级发布

7.4.1 每季度首月 **10 日前**，采购部汇总上季度数据，编制《供应商质量月度 / 季度评级表》（**QR-QC-07-01**），经品质部会签后发布。

7.4.2 评级表须同时反映：**准入状态**与**评级**两个字段（见第 3 节术语说明）。

## 8. 供应商变更管理

8.1 供应商发生下列变更，**须提前书面通知**我方（使用《供应商工艺变更通知单》，格式见 JC-GY 系列）：

| 变更类别 | 举例 |
|---|---|
| 材料变更 | 换用替代材料、换材料供应商 |
| **工艺变更** | 电镀工艺切换、热处理方式改变、焊接方法变更 |
| 设备变更 | 关键设备更换 |
| 生产场地变更 | 厂址迁移、新增 / 关闭产线 |
| 外协分包 | 将工序外委第三方 |

8.2 **收到通知后的处理**：

1. 采购部登记，转品质部与工艺部评估；
2. 品质部评估对来料质量的影响，必要时要求**试产样件**；
3. **重大变更**（影响表面处理、材料性能、关键尺寸）须经**技术副总**批准；
4. 批准后，切换后的**首批 3 批加严检验**（QP-06 §4.2.3）。

8.3 **未通知即擅自变更**的，按 7.3.1 的「诚信问题」处理，**直接进入观察期**。

> **提示**：供应商的工艺变更，尤其是**表面处理**类变更，往往不会立即在来料检验的外观与尺寸上体现，而会在**附着力、耐盐雾**等需要专项试验的项目上暴露。因此对表面处理类变更，**必须要求供应商提供变更后的专项试验数据**，不能只看外观与尺寸。

## 附录 A · 准入状态与评级的组合含义

| 准入状态 | 评级 | 含义 | 管理动作 |
|---|---|---|---|
| 合格 | A | 优质供应商 | 优先分配；可放宽检验 |
| 合格 | B | 常规供应商 | 常规管理 |
| 合格 | C | 绩效差但仍合格 | 加严检验；新订单受限 |
| **观察期** | A / B / C | **限期整改中**（评级保留历史值） | 加严 + 停新单 + 月度报告 |
| 暂停 | —— | 停止全部合作 | 寻找替代 |
| 淘汰 | —— | 已终止合作 | 12 个月内禁止重入 |

## 附录 B · 供应商现场审核要点

| 类别 | 审核项 |
|---|---|
| 体系 | 体系证书有效性；文件受控情况 |
| 过程 | 关键工序参数是否受控并有记录；作业指导书是否在现场 |
| 检验 | 是否有来料 / 过程 / 出厂检验；量具是否校准 |
| 追溯 | 能否由成品追溯到批次、原材料、操作者 |
| 变更 | 是否有变更管理流程；历史变更是否通知客户 |
| 现场 | 5S、物料标识、不合格品隔离 |
