## 1. 目的

规范生产工单的**下达、执行、完工确认**流程，明确**交期考核**的指标定义与计算口径。

## 2. 适用范围

适用于本公司全部**生产工单**（`生产工单` 表中的记录），包括自制件加工、装配与包装工序。

## 3. 术语与指标定义

### 3.1 工单状态

`生产工单` 表的「工单状态」字段取值**只有三种**：

| 状态 | 定义 |
|---|---|
| **已完工** | 已确认完工（无论是否按期） |
| **在制** | 已下达、尚未确认完工，且**计划完工日尚未到达** |
| **延期未完工** | **计划完工日已过**但仍未确认完工 |

> **⚠️ 注意**：状态为「**已完工**」**不代表按期完工**。实际完工日晚于计划完工日的工单，状态字段同样记为「已完工」。
> **是否按期须比对两个日期字段**（见 3.2），不能只看状态。

### 3.2 🔴 按期完工率（本文件的核心定义）

```
按期完工率 = 按期完工的工单数 ÷ 统计期内全部已下达工单数 × 100%

其中：按期完工 = (实际完工日 IS NOT NULL) AND (实际完工日 ≤ 计划完工日)
```

**口径说明**：

| # | 规则 | 说明 |
|---|---|---|
| 1 | **分母是全部已下达工单**，含**在制**与**延期未完工** | 在制工单在统计时点尚未兑现，**计入分母**（保守计法） |
| 2 | 「按期」的判定基准是**计划完工日**，不是计划开工日 | —— |
| 3 | 实际完工日为**空**的（在制 / 延期未完工）**一律不计入分子** | —— |
| 4 | 实际完工日**早于或等于**计划完工日的算按期 | 提前完工也算按期 |

> ### 🔴 关于口径的选择（易错点）
>
> 若把**在制工单从分母中剔除**（即「分母 = 已完工 + 延期未完工」），会得到一个**显著更高**的按期完工率。
> 例如某统计期内：全部工单 147 张、按期完工 117 张、在制 12 张。
>
> | 口径 | 计算 | 结果 |
> |---|---|---|
> | **本文件规定（含在制）** | 117 ÷ 147 | **79.6%** |
> | 剔除在制 | 117 ÷ (147 − 12) | 88.0% |
>
> **两者相差 8.4 个百分点，且都能「算对」。**
> 本公司**统一采用前者**（含在制），理由：跨月统计时「在制」的数量随时间变化，
> 剔除在制会使不同月份的按期率**不可比**，也无法反映「工单积压」这一管理问题。
>
> **凡对外报送或用于部门考核的按期完工率，一律采用含在制的口径。**
> 若内部需要评估「已到期的工单是否按期」这一更窄的问题，可另按剔除在制的口径计算，
> 但**必须在结论中明确注明口径**，且**不得与含在制口径的数据混用于同一张报表或同一句结论**。

### 3.3 延期率

```
延期率 = 1 − 按期完工率
```

**不单独定义**，直接由按期完工率推出，避免两个指标口径不一致。

### 3.4 计划达成率（数量维度）

```
计划达成率 = 完工数量合计 ÷ 计划数量合计 × 100%
```

该指标反映**数量**完成情况，与按期完工率（**时间**维度）互补。**两者须分别列示**，不得互相替代。

## 4. 工单管理流程

### 4.1 工单下达

4.1.1 计划科根据销售订单与库存情况编制生产计划，转为生产工单下达。

4.1.2 工单须包含：物料编码、计划数量、计划开工日、**计划完工日**。

4.1.3 计划完工日的确定：

| 工序类型 | 标准工时（自计划开工日起） |
|---|---|
| 机加工 | 5 ~ 15 天 |
| 焊接 / 装配 | 3 ~ 10 天 |
| 表面处理（外协） | 7 ~ 15 天 |
| 热处理 | 3 ~ 7 天 |
| 包装 | 1 ~ 3 天 |

4.1.4 **计划完工日一经下达不得随意变更**。确需变更的，须经生产部部长批准并记录原因（作为考核的免责依据）。

### 4.2 工单执行

4.2.1 车间按工单领料、加工、报工。

4.2.2 **进度报工**：每完成一道工序报工一次，系统记录完成数量。

4.2.3 **异常报告**：出现下列情形，车间须在 **4 小时内**报告计划科：

| 情形 | 说明 |
|---|---|
| 缺料 | 物料未到位或库存不足（见 QW-WM-02） |
| 设备故障 | 影响工单进度 |
| 质量异常 | 批量不合格需返工（见 QP-08） |
| 人员不足 | 影响排产 |

### 4.3 完工确认

4.3.1 工单全部工序完成、经检验合格后，由车间提交完工确认，系统记录**实际完工日**。

4.3.2 **完工数量少于计划数量**的：

| 情形 | 处理 |
|---|---|
| 差额 ≤ 3% | 视为完工，差额由损耗承担 |
| 差额 > 3% | 须说明原因；必要时补投产 |
| 因质量原因报废导致的差额 | 按 QP-08 记录，并计入质量成本 |

4.3.3 **工单不得长期挂账**。计划完工日已过 30 天仍未完工的，由生产部逐单说明原因并制定关闭计划。

## 5. 交期考核

### 5.1 考核对象

| 对象 | 考核指标 | 周期 |
|---|---|---|
| 各车间 | 按期完工率 | 月度 |
| 计划科 | 计划准确率（计划完工日变更率） | 月度 |
| 采购部 | 物料到料及时率（见 QP-05） | 月度 |

### 5.2 考核标准

| 按期完工率 | 评定 |
|---|---|
| ≥ 90% | 优 |
| 80% ~ 90% | 良 |
| 70% ~ 80% | 合格 |
| < 70% | **不合格**，须提交改善计划 |

### 5.3 按物料类别的差异

不同物料类别的加工难度与工序数差异较大，**考核时按类别分别统计**，不搞「一刀切」：

| 类别 | 工序特点 | 考核基准 |
|---|---|---|
| 电子元件 | 装配为主，工序少 | ≥ 90% |
| 包装材料 | 单一工序 | ≥ 90% |
| 标准件 | 标准化程度高 | ≥ 85% |
| 五金件、机加工件 | 多工序，易受设备影响 | ≥ 80% |
| 结构件、弹簧、塑胶件 | 中等 | ≥ 80% |
| 密封件 | 中等 | ≥ 80% |
| **铸件** | **工序最长、外协环节多** | **≥ 75%** |
| 轴承、线材 | 依赖外购件到货 | ≥ 75% |

> **铸件类为何基准更低**：铸件生产包含造型、熔炼、浇注、清砂、热处理、机加工等多道工序，
> 其中热处理与部分机加工环节涉及外协，**进度受外部因素影响大**，且单件周期长，
> 一旦某道工序延误，后续工序无法压缩。因此基准适当下调，但**不豁免考核**。

### 5.4 免责情形

下列原因导致的延期，**经批准后不计入考核**：

| 情形 | 批准人 |
|---|---|
| 物料未按期到货（供应商责任） | 采购部部长 |
| 图纸 / 工艺变更 | 工艺部部长 |
| 客户变更需求 | 销售部 + 生产部 |
| 设备突发故障（非维护不当） | 生产部部长 |
| 不可抗力 | 总经理 |

## 附录 A · 按期完工率计算示例

**场景**：2026 年 8 月，全部类别合计

| 项 | 数量 |
|---|---|
| 本月已下达工单 | **147** |
| ├ 已完工（含按期与延期完工） | 133 |
| ├ 在制（计划完工日未到） | 12 |
| └ 延期未完工（计划完工日已过） | 2 |
| 其中**按期完工**（实际完工日 ≤ 计划完工日） | **117** |
| **按期完工率（本文件口径）** | **117 ÷ 147 = 79.6%** |
| 对照：剔除在制口径 | 117 ÷ 135 = 86.7% |

**按类别的按期完工率（同一口径）**：

| 类别 | 按期完工率 |
|---|---|
| 电子元件 | 93.8% |
| 包装材料 | 87.5% |
| 五金件 | 86.7% |
| 标准件 | 84.0% |
| 结构件 | 81.8% |
| 弹簧、塑胶件 | 80.0% |
| 密封件 | 76.5% |
| 机加工件 | 73.3% |
| **铸件** | **70.0%** |
| 线材、轴承 | 60.0% |

> **观察**：铸件（70.0%）低于其考核基准（75%），**属应重点改善的类别**。
> 线材与轴承（均为 60.0%）为最低，须核查是否与**外购物料到货延迟**相关（见 5.4 免责情形）。
> **注意**：线材与轴承类的工单样本量较小（各 5 ~ 10 张），单月数据的波动大，
> 判定时应结合连续 3 个月的趋势，不宜凭单月数据下结论。
