## 1. 目的

统一物料编码规则与主数据字段定义，确保**全公司（采购、库存、生产、检验、财务）使用同一套物料标识**，避免一物多码或一码多物。

## 2. 适用范围

2.1 适用于本公司**全部物料主数据**的建立、变更与停用。

2.2 物料主数据是下列系统数据的**共同基准**：`采购订单`、`到料检验`、`库存`、`生产工单`。

## 3. 物料编码规则

### 3.1 编码结构

```
A 10 001
│  │   │
│  │   └── 流水号（3 位，按类别顺序编）
│  └────── 大类码（2 位）：10 = 通用生产物料
└───────── 首码（1 位）：A = 外购 / 原材料
```

| 位置 | 位数 | 含义 | 取值 |
|---|---|---|---|
| 首码 | 1 | 物料来源 / 形态 | **A** = 外购件与原材料；B = 半成品；C = 成品；D = 辅料与耗材 |
| 大类码 | 2 | 物料大类 | **10** = 通用生产物料（现行）；20 ~ 29 预留 |
| 流水号 | 3 | 顺序号 | 001 ~ 999 |

### 3.2 编码原则

3.2.1 **一物一码**：同一物料（功能、材质、规格均相同）**只允许一个编码**。

3.2.2 **一码一物**：一个编码**只能对应一种物料**，不得复用。

3.2.3 **编码不表达规格**：规格信息记录在「规格型号」字段，**不从编码推断**。
> 例如 A10001（DN50 PN16）与 A10002（DN80 PN16）同为「不锈钢法兰盘」，**规格不同即为不同物料**，各自独立编码。

3.2.4 **编码一经启用不得修改**。物料停用后编码**永久保留**，不得分配给新物料。

### 3.3 新增编码

3.3.1 新物料由**工艺部提出**、仓储部编码、技术副总批准后建立。

3.3.2 新增前须**查重**：按「物料名称 + 规格型号」检索，确认不存在同一物料。

3.3.3 同一名称不同规格的物料，**必须分别建立编码**，不得用同一编码的不同批次代替。

## 4. 主数据字段定义

### 4.1 字段清单

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| **物料编码** | 文本 | ✅ | 主键，见第 3 章 |
| **物料名称** | 文本 | ✅ | 通用名称，**不含规格** |
| **物料类别** | 文本 | ✅ | 见 4.2 |
| **规格型号** | 文本 | ✅ | 区分同名称物料的关键信息 |
| **单位** | 文本 | ✅ | 件 / 个 / 套 / 片 / 条 / 根 |
| **安全库存** | 数值 | ✅ | 全公司合计口径（见 **QW-WM-02 §3.2**） |
| **标准单价** | 数值 | ✅ | 见 4.3 |

### 4.2 物料类别

物料类别**只允许取以下 12 个值**，不得自行新增：

| 类别 | 含义 | 典型物料 |
|---|---|---|
| **五金件** | 金属结构类零件 | 不锈钢法兰盘 |
| **结构件** | 非金属或组合结构件 | 铝合金外壳 |
| **电子元件** | 电气 / 电子器件 | 主控电路板、电源模块、继电器、显示屏模组 |
| **塑胶件** | 注塑 / 吹塑件 | 注塑面板 |
| **铸件** | 铸造毛坯或成品 | 齿轮箱体、铸铁端盖 |
| **机加工件** | 经切削加工的功能件 | 轴承座、传动轴、同步带轮 |
| **轴承** | 滚动 / 滑动轴承 | 深沟球轴承 |
| **标准件** | 通用紧固与连接件 | 螺栓、垫圈、扎带 |
| **弹簧** | 弹性元件 | 压缩弹簧、拉伸弹簧 |
| **密封件** | 密封与减震元件 | O 型密封圈、骨架油封、橡胶减震垫 |
| **线材** | 线束类 | 电源线束、信号线束 |
| **包装材料** | 包装与缓冲材料 | 纸箱、珍珠棉内衬 |

> **类别的作用**：物料类别是**统计与考核的分组维度**（如 QP-09 的交期考核按类别分别统计、QP-07 的供应商类别对应关系）。
> 因此**类别的准确性直接影响分析结论** —— 归类错误会导致某类别的指标失真。

### 4.3 标准单价

4.3.1 **标准单价**是物料的**计划价格**，用于：
- 生产成本的**估算**；
- 采购预算编制；
- 库存资金占用的 valuation。

4.3.2 **标准单价 ≠ 实际采购单价**。实际采购单价记录在 `采购订单` 表中，可能因批量折扣、市场波动而不同。

> **🟠 统计口径提示**：计算**采购金额**时，必须使用 `采购订单` 表的「采购单价 × 采购数量」，
> **不得用「标准单价 × 采购数量」代替** —— 后者只是估算值。
> 而计算**库存资金占用**时，使用 `物料` 表的标准单价。
> **两者的用途不同，不可混用。**

4.3.3 标准单价**每年至少复审一次**；市场价格波动超过 15% 的，临时调整。

### 4.4 安全库存

安全库存字段的**设定方法、维护责任与预警规则**见 **QW-WM-02《安全库存设定与预警规则》**。

> **注意**：安全库存是**全公司合计口径**的目标值，**不是单仓目标值**。

## 5. 主数据维护

### 5.1 变更流程

| 变更类型 | 提出方 | 审核 | 批准 |
|---|---|---|---|
| 新增物料 | 工艺部 | 仓储部 / 采购部 | 技术副总 |
| 修改名称 / 规格 | 工艺部 | 仓储部 | 技术副总 |
| 修改安全库存 | 仓储部 | 生产部 | 技术副总 |
| 修改标准单价 | 采购部 / 财务部 | —— | 技术副总 |
| **停用物料** | 工艺部 | 仓储部 | 技术副总 |

### 5.2 变更控制

5.2.1 **物料编码与物料类别不得修改**。确需修改分类的，须**停用原编码、新建编码**，并保留对应关系记录。

5.2.2 所有主数据变更须**留痕**（变更人、变更时间、变更前后值、批准人）。

5.2.3 主数据变更**不影响历史单据** —— 已发生的采购订单、检验记录、工单继续引用原编码。

### 5.3 停用规则

5.3.1 物料停用前须确认：**无在途采购订单、无未完结工单、库存已清零**。

5.3.2 停用物料的编码**永久保留**，系统内标记为「停用」，不再出现在新建单据的下拉列表中。

## 附录 B · 编码使用中的常见错误

| # | 错误 | 后果 |
|---|---|---|
| 1 | 用「物料名称」作为物料的唯一标识 | 同名称多规格的物料被当成一种，统计与检验记录混淆 |
| 2 | 新增物料前不查重，凭印象建码 | 一物多码，库存被拆成多份，缺口看不出来 |
| 3 | 用批次号区分规格 | 批次是时间维度，不是规格维度，越用越乱 |
| 4 | 直接修改物料类别来「纠正」归类 | 历史单据的统计口径被追溯性改变，报表前后不可比 |
| 5 | 用标准单价算采购金额 | 与实际支付不符，成本核算失真 |
