## 1. 供货范围

本协议适用于乙方向甲方供应的下列物料：

| 物料编码 | 物料名称 | 规格型号 | 类别 | 单位 | 年预估量 |
|---|---|---|---|---|---|
| **A10002** | 不锈钢法兰盘 | DN80 PN16 | 五金件 | 件 | 6,000 |
| **A10014** | 弹簧垫圈 | M8 65Mn | 标准件 | 个 | 90,000 |
| **A10026** | 同步带轮 | 24 齿 5M | 机加工件 | 个 | 2,500 |

> 乙方供货能力覆盖**精密铸造、冲压、机加工**三类工艺，上述物料的工艺路线分别见第 3 章。
> 超出本范围的物料，须另行签订补充协议。

## 2. 通用要求

### 2.1 质量标准

2.1.1 全部物料须满足甲方图纸、本协议及 **QW-JS-01** 的要求。

2.1.2 表面处理件的验收标准按 **QW-JS-01 第 5 章**执行，其中**自制件与外购件统一适用**。

2.1.3 乙方**不得擅自变更**材料、工艺、设备、生产场地或外协分包。变更须提前书面通知甲方，按 **QP-07 第 8 章**处理。

### 2.2 检验与放行

2.2.1 甲方按 **QP-06** 执行到货检验，抽样方案为 `min(80, max(30, 到货数量 × 8%))`。

2.2.2 **判定阈值**：批次不良率 ≤ 3% 判合格。

2.2.3 乙方须随批提供**出厂检验报告**，报告至少包含：

| 项目 | 内容 |
|---|---|
| 基本信息 | 物料编码、批次号、生产日期、数量 |
| 检验项目 | 本协议第 3 章规定的**关键特性** |
| 实测值 | 每次检验的实测数据（非仅「合格」字样） |
| 检验员与日期 | 签署完整 |

2.2.4 **报告不得只写结论不写数据**。凡只标注「合格」而无实测值的报告，甲方有权退回并要求重新出具。

### 2.3 质量绩效

2.3.1 乙方的质量与交付绩效按 **QP-07 第 6 章**评价，**每季度一次**。

2.3.2 **不合格批次的触发动作**（同 QP-06 §4.6.3、QP-08 §6.1）：

| 情形 | 动作 |
|---|---|
| 连续 2 批不合格 | 发 **SCAR**，要求 **7 个工作日内**提交 8D 报告；评级降一级 |
| 近 3 个月内累计 3 批不合格 | 同上 |
| 单季度不良率 > 5% | 直接进入**观察期** |

2.3.3 8D 报告中**不得以「操作人员疏忽」作为唯一根本原因**（见 QP-08 §6.2.2）。

### 2.4 交付要求

2.4.1 交期按每张采购订单的「约定交期」执行（见 **QP-05**）。

2.4.2 **准时交付率**的计算口径按 **QP-07 §6.3**：

```
准时交付率 = (到料日期 ≤ 约定交期 的批次数) ÷ (统计期内实际到料批次数) × 100%
```

2.4.3 **交付绩效要求**：

| 等级 | 准时交付率 | 管理措施 |
|---|---|---|
| 达标 | ≥ 90% | 常规 |
| **预警** | **70% ~ 90%** | 甲方发出书面提醒，要求提交改善计划 |
| **不达标** | **< 70%** | **订单分流**；纳入季度评级降级参考 |

> **⚠️ 乙方当前状态提示**：截至 2026 年 8 月，乙方**准时交付率低于 70%**，
> 已触发甲方的书面提醒与订单分流评估。
> **主要原因**（甲方分析）：铸件类工序周期长，且乙方热处理环节依赖外协，
> 外协排期不受乙方控制。
>
> **甲方要求**：乙方须在 **2026 年 9 月 30 日前**提交改善方案，内容包括：
> 1. 外协环节的备选供应商方案（至少 1 家）；
> 2. 关键工序的自制化评估；
> 3. 交期承诺的**可达性复核**（乙方在接单时的交期评估方法）。

2.4.4 **禁止以赶工为由压缩工艺时间**。特别是：

- 铸件的**时效处理**与**热处理**时间不得压缩；
- 涉及去氢的件（见 QW-JS-01 §5.5）**镀后 4 小时内**必须进烘箱，不得推迟。

## 3. 各物料的专项要求

### 3.1 A10002 不锈钢法兰盘（DN80 PN16）

| 项目 | 要求 |
|---|---|
| 材质 | 304 不锈钢（须提供材质证明书） |
| 工艺路线 | 熔模铸造 → 固溶处理 → 机加工（密封面、螺栓孔）→ **钝化** |
| 关键特性 | ① 密封面平面度；② 螺栓孔位置度；③ 法兰外径与厚度 |
| 尺寸公差 | 按图纸；未注公差按 GB/T 1804-m |
| 表面处理 | **钝化（代号 SS）**，不得有锈斑；按 QW-JS-01 §5.2 外观要求 |
| 无损检测 | 每批抽 2 件做**渗透检测（PT）**，不得有裂纹 |
| 包装 | 密封面加保护套；每箱不超过 50 件 |

### 3.2 A10014 弹簧垫圈（M8 65Mn）

| 项目 | 要求 |
|---|---|
| 材质 | 65Mn 弹簧钢带 |
| 工艺路线 | 冲制 → 淬火 + 回火 → **表面处理** |
| 关键特性 | ① **弹性**（自由高度与压并高度）；② 内径；③ 硬度 |
| 硬度 | HRC 42 ~ 48 |
| 表面处理 | **氧化（发黑，代号 Ox）**；不得有氢脆风险残留 |
| **去氢要求** | **本件须做去氢处理**（硬度 > 40 HRC，属氢脆敏感件） |
| 抽样 | 每批抽 30 件做弹性试验 |

> **关于去氢**：按 **QW-JS-01 §5.5**，基体抗拉强度 ≥1000 MPa（或硬度 ≥40 HRC）的件**必须去氢**，
> 且镀后 **4 小时内**进入烘箱。乙方须提供去氢处理记录（含时间戳），
> **甲方有权在到货时核查该记录**。无记录的批次按不合格处理。

### 3.3 A10026 同步带轮（24 齿 5M）

| 项目 | 要求 |
|---|---|
| 材质 | 45 钢（正火态）或 HT250 铸铁（乙方选择，须在首次交货时声明） |
| 工艺路线 | 铸造 / 锻造毛坯 → 车削 → **齿形加工** → 齿面处理 |
| 关键特性 | ① **齿形参数**（齿距、齿高）；② 节圆直径；③ 齿面粗糙度 Ra ≤ 3.2 |
| 齿形精度 | 按 GB/T 11361；齿距累积误差 ≤ 0.05 mm |
| 动平衡 | 转速 > 3000 rpm 的应用须做动平衡（图纸注明时） |
| 表面处理 | 发黑（Ox）；齿面不得有毛刺 |
| 包装 | 齿面加保护；防锈处理 |

## 4. 不合格处置

4.1 不合格批次的处置按 **QP-08 第 5 章**执行，方式限于：退货 / 让步接收 / 挑选使用 / 报废。

4.2 **挑选使用的费用由乙方承担**（QP-08 §5.2）。

4.3 **表面处理类缺陷**的处置按 **QP-08 §5.3**：

| 缺陷 | 处置 |
|---|---|
| 起泡 | **不得返工，直接报废**（乙方承担） |
| 附着力不足 | 视基体状态，返工或报废 |
| 厚度不达标 | 返工（补镀） |

## 5. 追溯性

5.1 乙方须能由**成品批次追溯到**：原材料批次、关键工序的操作者与设备、检验记录。

5.2 追溯记录保存 **3 年**，甲方有权查阅。

## 6. 变更管理

6.1 乙方发生 **QP-07 §8.1** 所列任一变更，须**提前书面通知**甲方。

6.2 **未通知即擅自变更**的，按 **QP-07 §8.3** 处理（直接进入观察期）。

6.3 变更批准后，切换批次**首批 3 批加严检验**（抽样加倍，阈值 1.5%）。
