## 1. 目的

规定本公司各生产工序的**安全操作要求、防护措施与应急处置**，防止人身伤害与设备事故。

## 2. 通用安全要求

2.1 进入车间**必须**穿戴：安全帽、工作服、劳保鞋。长发须束入帽内。

2.2 **严禁**在车间内吸烟、饮食、追逐打闹。

2.3 **严禁**酒后或服用影响判断力的药物后上岗。

2.4 操作设备前须**确认**：防护罩齐全、急停按钮有效、警示标识清晰。

2.5 **严禁**擅自拆除、短接安全防护装置（如限位器、光电保护、联锁开关）。

2.6 发现安全隐患，**任何人有权限停止作业**并报告。

2.7 交接班时须**交接安全事项**（设备异常、危险作业、隐患整改）。

## 3. 表面处理作业安全规程

> 本章与 **QW-DD-03《电镀作业指导书》第 9 章**配套使用。工艺参数见 QW-DD-03 §6.1。

### 3.1 危化品接触防护

| 物质 | 危害 | 防护要求 |
|---|---|---|
| 盐酸（酸洗槽） | 腐蚀、酸雾刺激 | 耐酸碱手套 + 护目镜 + 防酸口罩；槽边抽风必须开启 |
| 三价铬钝化剂 | 刺激性 | 耐酸碱手套 + 护目镜；**严禁徒手操作** |
| 除油剂（碱性） | 灼伤 | 耐碱手套 + 护目镜 |
| 封闭剂 | 轻微刺激 | 手套 |

**强制要求**：

3.1.1 **槽边抽风必须开启**后才能开始作业。抽风故障时**立即停止作业**。

3.1.2 **补加药水**时须佩戴耐酸碱手套与护目镜，**严禁徒手操作**（同 QW-DD-03 §8.1.2）。

3.1.3 药水存放于**阴凉通风处，远离酸类**，容器加盖并标识名称（同 QW-DD-03 §8.1.1）。

### 3.2 用电安全（整流器）

| 风险 | 措施 |
|---|---|
| 触电 | 挂具带电时**严禁徒手入槽**；整流器柜门上锁 |
| 接地失效 | **接地电阻每季度检测**，记录留存 |
| 短路 | 槽内不得有金属杂物；发现打火立即断电 |

### 3.3 高温作业

3.3.1 烘干箱、去氢炉取件**必须戴隔热手套**。

3.3.2 去氢炉温度达 **190 ~ 220 °C**，**严禁**在炉门开启状态下将身体伸入。

### 3.4 滑倒防护

3.4.1 槽间通道**保持干燥**，地面溢液**即时清理**。

3.4.2 通道须铺设**防滑垫**；防滑垫破损的**立即更换**。

3.4.3 禁止跨越槽体、禁止在槽沿上行走。

### 3.5 应急设施

| 设施 | 位置 | 检查频次 |
|---|---|---|
| **洗眼器** | 车间西侧 3 m 处 | 每周（畅通、出水正常） |
| 应急喷淋 | 车间入口 | 每周 |
| 急救箱 | 车间办公室 | 每季度（药品有效期） |
| 酸雾报警器 | 酸洗区上方 | 每月 |

## 4. 机加工作业安全规程

| 设备 | 主要风险 | 防护措施 |
|---|---|---|
| 数控车床 | 工件飞溅、缠绕 | 关闭防护门后才启动；**严禁戴手套**操作旋转部件 |
| 铣床 | 铁屑飞溅、刀具伤手 | 戴护目镜；用毛刷清屑，**严禁徒手** |
| 钻床 | 钻头断裂、工件甩出 | 工件必须**夹紧**；严禁手持小件钻孔 |
| 磨床 | 砂轮破裂、粉尘 | 砂轮须有防护罩；佩戴防尘口罩 |
| 砂轮机 | 砂轮破裂 | 启动后**空转 1 分钟**再磨；严禁站在砂轮正面 |

**通用要求**：

4.1 **严禁**在设备运转时测量、清洁、调整。

4.2 **严禁**用手或棉纱清理铁屑，须用**专用钩子或毛刷**。

4.3 清理切屑前**必须停机**。

## 5. 焊接与切割作业安全规程

5.1 **动火作业须办证**（《动火作业许可证》），经安环科批准。

5.2 作业前**清理周边可燃物**（半径 5 m 内）；配备灭火器。

5.3 焊接须佩戴**焊接面罩**，防止弧光伤眼。

5.4 气瓶管理：

| 要求 | 说明 |
|---|---|
| 立放 | 气瓶须**立放**并固定，严禁卧放 |
| 间距 | 氧气瓶与乙炔瓶间距 **≥ 5 m** |
| 距火源 | ≥ 10 m |
| 防倒 | 用链条或支架固定 |
| 防曝晒 | 避免阳光直射 |

5.5 作业完毕**检查余火**，确认无火种后方可离开。

## 6. 装配作业安全规程

6.1 压装机作业**严禁**手伸入压头下方；须使用**专用工具**取放件。

6.2 使用扭矩扳手时**注意反作用力**方向，防止手腕扭伤。

6.3 搬运重物（> 25 kg）须**两人协作或使用行车**，严禁单人硬搬。

6.4 行车作业须**持证操作**（特种设备作业证）；吊物下**严禁站人**。

## 7. 危险化学品管理

### 7.1 分类与储存

| 类别 | 示例 | 储存要求 |
|---|---|---|
| 酸性 | 盐酸、钝化剂 | **与碱类分开**；耐酸柜 |
| 碱性 | 除油剂 | 与酸类分开 |
| 易燃 | 清洗剂、油漆 | 独立危化品库；远离火源 |
| 氧化性 | 双氧水 | 单独存放 |

### 7.2 管理要求

7.2.1 **危化品须有 SDS**（安全技术说明书），存放于使用现场**便于查阅**处。

7.2.2 **入库 / 领用 / 使用 / 废弃**须登记（《危化品台账》）。

7.2.3 容器须**标识清楚**，**严禁用饮料瓶等非专用容器盛装**。

7.2.4 危废（废药水、废抹布）分类收集，交**有资质单位**处理，不得随意倾倒。

## 8. 应急处置

| 情形 | 处置步骤 |
|---|---|
| **药水溅入眼睛** | 立即用**洗眼器冲洗 15 min 以上** → 送医（不得自行用药） |
| **药水溅到皮肤** | 大量清水冲洗 15 min → 视情况送医 |
| **酸雾吸入** | 迅速转移至通风处 → 严重者送医 |
| **触电** | **先断电**（不得直接拉扯伤者）→ 急救 → 送医 |
| **烫伤** | 冷水冲洗 15 min → 覆盖干净纱布 → 送医（**不得涂抹牙膏等**） |
| **切割 / 扎伤** | 止血 → 消毒包扎 → 送医；**伤口较深的须注射破伤风** |
| **化学品泄漏** | 疏散 → 用吸附材料围堵 → 中和处理 → 记录上报 |
| **火灾** | 报警 → 断电 → 用对应灭火器（**电气火灾禁用水**） |
| 设备卷入 | **立即按急停**，不得强行拉扯被卷部位 |

| 类别 | 电话 |
|---|---|

| 急救 | 120 |
