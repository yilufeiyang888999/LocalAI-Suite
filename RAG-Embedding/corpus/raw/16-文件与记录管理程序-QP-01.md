## 1. 目的

规定质量管理体系**文件的编制、审批、发布、修订、回收与作废**，以及**记录的填写、保存与处置**要求，确保各场所使用的文件均为**有效版本**，记录**真实、完整、可追溯**。

## 2. 适用范围

2.1 适用于本公司质量管理体系覆盖的**全部文件与记录**，包括：程序文件、作业文件、记录表单、外来文件。

2.2 适用于**纸质与电子**两种形式。

## 3. 文件分类与编号规则

### 3.1 文件分类

| 类别 | 代号 | 定义 | 举例 |
|---|---|---|---|
| **质量手册** | QM | 体系纲领性文件 | QM-2025 |
| **程序文件** | **QP** | 规定「谁、何时、做什么」的跨部门流程 | QP-06 来料检验控制程序 |
| **作业文件** | **QW** | 规定「怎么做」的技术性文件 | QW-DD-03 电镀作业指导书 |
| **记录表单** | **QR** | 承载记录的空表模板 | QR-QC-08-02 |
| **外来文件** | **JC / JS / GB** | 供应商通知、技术协议、国家标准 | JC-GY-2026-006 |

### 3.2 编号结构

```
QP - 06
│    │
│    └── 顺序号（2 位）
└─────── 类别代号

QW - DD - 03
│    │    │
│    │    └── 顺序号
│    └─────── 归口部门码
└──────────── 类别代号

QR - QC - 08 - 02
│    │    │    │
│    │    │    └── 该程序下的记录序号
│    │    └─────── **归属的程序文件号**
│    └──────────── 归口部门码
└───────────────── 类别代号
```

**归口部门码**：

| 码 | 部门 | 码 | 部门 |
|---|---|---|---|
| **DD** | 表面处理车间（电镀） | **WM** | 仓储部 |
| **QC** | 品质部 | **SB** | 设备科 |
| **JS** | 工艺技术 | **AQ** | 安环科 |
| **SC** | 生产部 | **CG** | 采购部 |

> **记录编号的归属含义**：`QR-QC-08-02` 表示「**QP-08** 不合格品控制程序」下的**第 2 号**记录。
> 因此由记录编号即可**反查其归属的程序文件**，无需另查台账。

### 3.3 外来文件的处理

3.3.1 外来文件（供应商通知、技术协议、国家标准）**不纳入本公司编号体系**，按**来文单位自编文号**登记：

| 前缀 | 含义 | 举例 |
|---|---|---|
| **JC-GY-** | 供应商工艺类通知（精诚） | JC-GY-2026-006 |
| **JS-XY-** | 技术协议 | JS-XY-2026-003 |
| **GB / GB/T** | 国家标准 | GB/T 9286 |

3.3.2 外来文件须登记于《外来文件台账》（**QR-XC-01-01**），并**评估其对本公司文件的影响**：

> 例如收到供应商的工艺变更通知（JC-GY 系列）后，品质部须评估是否需要**加严检验**、
> 是否需要**更新验收标准**，评估结论记录于台账。

## 4. 文件的编制与审批

### 4.1 审批权限

| 文件类别 | 编制 | 审核 | 批准 |
|---|---|---|---|
| 质量手册 | 品质部 | 管理者代表 | **总经理** |
| **程序文件（QP）** | 归口部门 | 品质部 | **总经理** |
| **作业文件（QW）** | 归口部门 | 归口部门主管 | **技术副总** |
| 记录表单（QR） | 使用部门 | 品质部 | 品质部部长 |

### 4.2 版次规则

| 标记 | 含义 | 触发 |
|---|---|---|
| **字母版**（A/B/C…） | **换版** | 文件结构重大调整、依据标准换版 |
| **修订次数**（第 1/2/3 次） | **修订** | 局部内容修改 |

> **示例**：`C 版 / 第 2 次修订` 表示该文件已换版至 C 版，且在 C 版基础上修订过 2 次。
> 换版时修订次数**归零重新计数**。

## 5. 文件的发布与回收

### 5.1 受控与非受控

| 类型 | 标识 | 用途 |
|---|---|---|
| **受控** | 加盖「受控文件」章、编流水号 | 内部使用，失效时**强制回收** |
| **非受控** | 加盖「非受控」章 | 提供给客户 / 外部机构，**不跟踪回收** |

5.1.1 车间现场使用的作业指导书**必须为受控版本**。

5.1.2 提供给客户的**非受控**文件，更新时**不强制更换**，但应在封面注明「非受控，仅供参考」。

### 5.2 发放与回收

5.2.1 文件发布由文控填写《文件发放回收记录》（**QR-XC-01-02**），逐份登记领取人。

5.2.2 **新版发布时，旧版须同时回收**。回收的旧版文件：

| 处理 | 说明 |
|---|---|
| 加盖「作废」章 | 保留 1 份存档（**作废留档**） |
| 其余销毁 | 纸质粉碎 / 电子加密删除 |

5.2.3 因**培训或追溯**需要保留旧版的，须加盖「作废留档」章并**单独存放**，**不得在现场使用**。

### 5.3 现场文件的维护

5.3.1 各车间主管须**每月检查**现场文件的版本有效性，确认无过期文件。

5.3.2 发现现场有过期文件的，**立即撤下**并报文控。

## 6. 文件的修订

6.1 修订的提出来源：

| 来源 | 说明 |
|---|---|
| 内部 | 实施中发现不适用、流程变更 |
| 外部 | 标准换版、客户要求、供应商变更（JC 系列） |
| 审核 | 内审 / 外审发现的不符合项 |
| 事故 / 客诉 | 纠正措施要求修改文件 |

6.2 修订流程与编制流程一致（第 4 章）。

6.3 **修订须填写《文件修订履历》**（位于每份文件末尾），内容包括：版本、日期、修订内容、修订人。

6.4 修订后的文件**重新发布**，旧版按 5.2.2 回收。

## 7. 记录管理

### 7.1 记录填写要求

| 要求 | 说明 |
|---|---|
| **真实** | 不得编造；不得事后补填（特殊情况须注明） |
| **及时** | 当场填写，不得批量补记 |
| **清晰** | 用**不褪色笔**；不得用铅笔 |
| **完整** | **不得留空**；无内容填「/」或「——」 |
| **可追溯** | 签名 + 日期 |
| **更正规范** | 划**单横线**更正，**不得涂改**；在旁边写正确值并**签名** |

> **禁止事项**：使用涂改液、撕页、事后整页重抄。

### 7.2 记录的保存

7.2.1 记录由**归口部门**保管，具备**防潮、防虫、防火、防丢失**条件。

7.2.2 **电子记录**须定期备份（每周一次），备份介质异地存放。

7.2.3 记录保存期限见 **附录 A**。**超过保存期限**的记录，由归口部门填写《记录销毁申请单》（**QR-XC-01-03**），经品质部批准后销毁。

### 7.3 记录的查阅

7.3.1 **内部查阅**：经归口部门同意。

7.3.2 **客户 / 第三方查阅**：经品质部同意，且有本公司人员陪同。

7.3.3 涉及**供应商工艺参数**的记录（如供方变更通知），对外提供前须**征得供应商同意**。
