## 五、口径与局限（必读）

- 本题库为**全新拟题**，没有金标准合取（与 `eval/题目.json` 的检索实验题不同），因此**不判「意思对不对」**（那要人工逐题读），只判三件可自动判定的事。
- **要点命中**：答案里是否出现本该出现的关键事实（题库 `参考要点`，已用护栏校验每条都能在语料中逐字查到）。命中 ≠ 答对；但**不命中基本等于没答到**。
- **数值无编造**：答案里的数值（百分比 / 文档编号 / 带单位的量，如 °C、μm、h）必须逐字出现在服务返回的 context 里。分母是**数值个数**不是题数 —— 「答案一个数值都没有」记 N/A、不记满分（否则判据分不清「通过」和「没检查」）。
- **拒答正确**：库外题必须拒答；库内题不得被误拒。
- 评分口径：库内题 = 70×要点率 + 15×数值忠实 + 15×未误拒（答案无数值时，忠实度的 15 分并入要点，即 85×要点率 + 15×未误拒）；库外题 = 拒答 100 / 未拒 0。
- 生成失败（超时 / 服务不可达）**不计入分母**并在表中标注；把失败当答错会把平均分冲成假的低值。
- **平均分不是「答对率」** —— 它是上面三条自动判据的加权，用于横向比较与回归监控，不代表「这个百分比的答案就是对的」。
- **自动判据查不出的两类问题**：① 答案自相矛盾（如首词与后文相反）；② 数值「碰巧」与 context 一致但语义错位。这两类靠「人工复核」列与抽样精读。
