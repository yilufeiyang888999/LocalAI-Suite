现有语料

统计口径与 /health 一致：docs / blocks 是唯一能区分新旧基座的字段。

新增文档

支持 md / txt / csv / docx / xlsx / pdf。流程是 上传 → 影子预检 → 人工确认 → 入库并热重建。
刻意**不做「上传即入库」** —— 文号与标题层级是语义，自动猜必错，而猜错的后果是「检索悄悄变差」，界面上看不到任何异常。
扫描件 PDF 无文本层，需先用 OCR 转出文字再入库。

把文件拖到这里，或点击选择
可多选。文件只发到本机 127.0.0.1 的服务，不出网。
